3. VPython 시뮬레이션3D 주차장 격자망에서 차량 객체가 빈 주차 공간으로 이동.

Web VPython Code
from vpython import *

# 주차면 좌표 (x, y, z)
slots = [vector(-5,0,0), vector(0,0,0), vector(5,0,0)]
occupied = [True, False, True] # 2번 자리가 비어있음

# 차량 및 주차장 생성
car = box(pos=vector(0,0,-10), size=vector(2,1,4), color=color.cyan)

# 최단 빈 공간 탐색
target = None
for i in range(len(slots)):
    if not occupied[i]:
        target = slots[i]
        break

# 자율주행 이동
while mag(car.pos - target) > 0.1:
    rate(30)
    dir = norm(target - car.pos)
    car.pos += dir * 0.2
print("주차 완료")

1. 문제 발견스쿨존 보행자의 무단횡단 및 돌발 진입 사고.
2. 발명 아이디어보행 신호 적색 시 물리 차단 바(Bar) 하강.
3. Turtle 시뮬레이션신호등 색상에 따라 차단 바 승강 연출.
4. 알고리즘 적용유한 상태 머신(FSM) 인터락 제어 logic.
5. 데이터 측정차단기 작동 후 횡단보도 침범 건수 감소율.
6. 개선손 끼임 방지 끼임 감지 시 자동 반전 승상 로직.
Python Turtle Code
import turtle

bar = turtle.Turtle()
bar.pensize(8)

signal = "RED" # 보행자 신호

if signal == "RED":
    bar.color("red")
    bar.forward(100) # 차단막 내려옴
    print("보행 금지: 차단기 작동")
else:
    bar.color("green")
    bar.left(90); bar.forward(100) # 차단기 열림
turtle.done()

16. 도서관 오배치 도서 탐지 로봇

Python Turtle
1. 문제 발견잘못된 위치의 책으로 인한 이용자 검색 불편.
2. 발명 아이디어서가 청구기호를 순차 스캔하여 순서 오류 도서 탐지.
3. Turtle 시뮬레이션로봇 거북이가 서가를 따라 이동하며 번호 검사.
4. 알고리즘 적용선형 탐색 정렬 검사(Ascending Order Check).
5. 데이터 측정100권 당 오배치 도서 탐지 정확도.
6. 개선오배치 도서의 원래 정위치 서가 안내 기능 추가.
Python Turtle Code
import turtle

scanner = turtle.Turtle()
books = [101, 102, 105, 103, 106] # 103번 오배치

prev = 0
for i, book in enumerate(books):
    scanner.goto(i * 30, 0)
    if book < prev:
        scanner.dot(15, "red")
        print(f"오배치 도서 발견: 번호 {book}")
    else:
        scanner.dot(10, "green")
    prev = book
turtle.done()

17. 신선도 유지 스마트 무인 택배함

Python Turtle
1. 문제 발견냉장 택배의 방치로 인한 식품 변질 문제.
2. 발명 아이디어품목 데이터 파싱 후 내부 온도 능동 제어.
3. Turtle 시뮬레이션택배함 셀 상태 및 온도 모니터링 시각화.
4. 알고리즘 적용목표 온도 유지 On/Off 릴레이 제어.
5. 데이터 측정외기온 상승 시 보관함 내부 온도 유지 성능.
6. 개선수령 지연 시 수령인에게 재촉 알림 유도 logic.
Python Turtle Code
import turtle

box = turtle.Turtle()
is_fresh_food = True
current_temp = 12 # 현재 12도

if is_fresh_food and current_temp > 4:
    box.color("blue") # 냉장 모드 가동
    box.begin_fill()
    for _ in range(4): box.forward(50); box.left(90)
    box.end_fill()
    print("신선 식품 감지: 냉장기 가동 (목표 4도)")
turtle.done()

18. 탁도 감지 텀블러 자동 세척기

Python Turtle
1. 문제 발견덜 닦인 세제로 인한 위생 및 건강 위협.
2. 발명 아이디어세척 배출수의 탁도를 감지해 세척 횟수 동적 결정.
3. Turtle 시뮬레이션세척 회차별 탁도 감소 그래프 시각화.
4. 알고리즘 적용탁도 수치 조건 만족 시까지 반복 Loop.
5. 데이터 측정고정 시간 세척 대비 세척 용수 절감량.
6. 개선용기 깊이에 맞춰 노즐 이동 높이 조절 로직.
Python Turtle Code
import turtle

cleaner = turtle.Turtle()
turbidity = 80 # 초기 탁도
wash_count = 0

while turbidity > 10: # 탁도 10 이하까지 세척
    wash_count += 1
    turbidity -= 25 # 세척 1회당 탁도 감소
    cleaner.goto(wash_count * 30, turbidity)
    cleaner.dot(10, "blue")

print(f"총 {wash_count}회 세척 후 완료 (탁도 {turbidity})")
turtle.done()

20. 공공도서관 좌석 점유 자동 관리기

Python Turtle
1. 문제 발견좌석에 물건만 두고 장시간 자리를 비우는 독점 문제.
2. 발명 아이디어좌석 인체 센서 연동 이석 타임아웃 시 자동 퇴실.
3. Turtle 시뮬레이션좌석 그리드 상의 이석 시간 카운트다운 표시.
4. 알고리즘 적용타이머 상태 머신(State Machine) 카운트다운.
5. 데이터 측정좌석 회전율 증가폭 및 자동 회수 건수.
6. 개선외출 버튼 입력 시 유예시간(30분) 예외 로직 부여.
Python Turtle Code
import turtle

seat = turtle.Turtle()
seat.shape("square"); seat.shapesize(2, 2)

is_occupied = False # 사람 없음
absence_time = 40  # 40분째 이석 중 (기준 30분)

if not is_occupied and absence_time > 30:
    seat.color("green") # 사용 가능 전환
    print("이석 시간 초과: 자동 퇴실 처리 (좌석 개방)")
else:
    seat.color("red")
turtle.done()
